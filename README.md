# Vista Venture Co. Starter Website

This is a clean GitHub Pages / Jekyll starter site for the Vista Venture Co. redesign.

## Pages included

- Home
- Services overview
- Web Design
- Photography
- Real Estate Media
- Dayframe
- Other Services
- An examples page for each service
- Our Work
- About Vista Venture
- Contact
- Thank-you page
- 404 page
- Internal appointment notes form at `/admin/notes.html`

## Media organization

Add images and videos inside `assets/media/`.

Examples:

- `assets/media/web-design/projects/eagle-rock-storage/homepage-desktop.webp`
- `assets/media/real-estate/boundary-overlays/elkins-acreage-overlay.webp`
- `assets/media/photography/food/restaurant-dish-01.webp`

A file can be displayed on any page even though it stays inside its correct service folder.

## Important notes

- GitHub does not save empty folders, so `.gitkeep` files are included.
- The admin notes page is not linked in the public navigation, but it is not password protected.
- Replace placeholder cards with actual images, videos, and project information as the site develops.
- The public contact form and internal notes form currently use the existing Formspree endpoint.
